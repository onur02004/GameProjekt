# Dies ist das Repo für das Game-Projekt der FSE

## Das Spiel:
Dieses Spiel ist ein Couch coop Spiel das auf einem Fehrnsehr gespielt wird, jder Spieler kann seinen Character über sein Handy steuern und muss darauf gelegentlich Rätsel lösen.
Das Spiel wird auf einem Server gehostet und die Spieler können über einen code mit ihren Handys beitreten.
